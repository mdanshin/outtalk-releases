Установка и обновления

Скачивайте OutTalk с официального сайта или по ссылке на выпуск, которую предлагает сайт. Не устанавливайте неизвестные копии из писем и сторонних каталогов.

Windows

Выберите сборку для Windows и запустите установщик. У portable-версии, если она предлагается, порядок запуска и обновления может отличаться.

У текущих неподписанных сборок Windows может показать предупреждение об издателе. Перед разрешением запуска проверьте, откуда получен файл. Предупреждение не является подтверждением безопасности приложения.

macOS

Скачайте сборку для вашего Mac, откройте загруженный образ и перенесите приложение в «Программы» по инструкции в образе.

Неподписанную сборку система может заблокировать. Разрешайте запуск через средства операционной системы только после проверки источника. Не отключайте общую защиту устройства ради установки.

Обновления

Версия показана в «Настройки → О программе». Там же можно проверить сведения о новом выпуске.

Установочная версия Windows может загрузить обновление и установить его при перезапуске. У неподписанной сборки macOS обновление требуется скачать и установить вручную. Для portable-версии следуйте показанной приложением инструкции.

Начиная с версии 0.1.26 приложение стало компактнее: установщик для macOS — около 115 МБ, установленное приложение — около 265 МБ.

Перед перезапуском завершите отправку и сохраните незавершённые письма. После ручной установки проверьте номер версии в настройках.

Переустановка

Переустановка приложения и удаление его данных — разные действия. Перед очисткой данных или переходом на другой компьютер проверьте местное хранение и перенос.

Если установка или обновление не удаются, используйте раздел решения проблем.
