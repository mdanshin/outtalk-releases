Обзор проектаOutTalk — продвинутый настольный почтовый клиент для macOS и Windows, построенный на Electron. Это самостоятельный многофункциональный продукт, а не оболочка длБыстрый старт- Node.js v24 (см. .nvmrc). Проект кросс-платформенный — разработка ведётся на macOS и Windows.
