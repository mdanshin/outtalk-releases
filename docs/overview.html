Введение

Обзор проекта

OutTalk — продвинутый настольный почтовый клиент для macOS и Windows, построенный на Electron. Это самостоятельный многофункциональный продукт, а не оболочка для одной почтовой системы. Сейчас полностью поддерживается корпоративный Microsoft Exchange через протокол EWS (Exchange Web Services); архитектура позволяет добавлять Gmail, IMAP и другие провайдеры без переработки интерфейса и доменного ядра.

Философия

  • Продукт важнее провайдера. Письма, беседы, календарь, поиск, черновики, вложения, горячие клавиши и расширения составляют OutTalk. Совместимость с конкретными серверами — возможность продукта, а не его определение.
  • Провайдер-агностичное ядро. Весь код выше слоя провайдеров оперирует единой доменной моделью и ничего не знает про EWS/IMAP/Graph. Добавление нового бэкенда = новый класс, реализующий интерфейс MailProvider, плюс одна ветка в фабрике.
  • Безопасность по умолчанию. Секреты шифруются средствами ОС и никогда не покидают машину. HTML писем санитайзится перед рендером. Рендерер изолирован (contextIsolation).
  • Документация как код. Эта документация — часть репозитория (Markdown в src/renderer/src/content/docs/), версионируется вместе с кодом и рендерится прямо в приложении. Любое изменение кода сопровождается обновлением соответствующего раздела.
  • Красота и детали. Дизайн-система, две темы, анимации — на уровне лучших продуктов.

Текущий статус

  • ✅ Шаблон приложения и дизайн-система.
  • ✅ MVP Exchange: папки, список писем, чтение (санитайзенный HTML), вложения, отправка/ответ/пересылка, прочитано/непрочитано, флаг, удаление, поиск в папке, пагинация.
  • ✅ Подтверждено на живом сервере Exchange 2016.
  • ✅ Серверный поиск по папке (EWS AQS) и inline-картинки (cid: → data:).
  • ✅ Календарь День/Неделя/Месяц: непрерывная лента дней и недель, неподвижная шкала времени, выделенные выходные, настраиваемый рабочий день.
  • ✅ Контакты: поиск по личной адресной книге и корпоративному GAL; карточка человека со сведениями из справочника (должность, отдел, офис, телефоны, руководитель и подчинённые) — одна и та же в письме и в адресной книге.
  • ✅ Надстройки Outlook, развёрнутые администратором Exchange: проверка в Настройках и кнопки надстроек (например, сервиса видеовстреч) в окне новой встречи своего ящика — своя прослойка office.js, брокер в main, отдельная сессия на надстройку (Exchange: надстройки Outlook, ADR-0139). Живой прогон с настоящей надстройкой — впереди.
  • ⏳ Exchange «до конца»: расширяемая область поиска «Везде», сериализация нескольких аккаунтов, пакетная загрузка вложений и дальнейшее усиление надёжности.
  • 🔜 Gmail/IMAP и расширение контактов до полного списка и редактирования.
