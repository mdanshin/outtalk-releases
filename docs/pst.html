Работа в приложении

Экспорт и импорт файла Outlook (.pst)

OutTalk выгружает почту в файл данных Outlook (.pst) и загружает такой файл обратно — так же, как «Импорт и экспорт» в Outlook. Файл открывается в Outlook, его можно хранить как архив или перенести почту в другой ящик.

Выгрузить ящик или папку

  1. Откройте окно экспорта одним из способов:
    • меню «Файл → Экспорт и импорт (.pst)…» (на macOS — в меню OutTalk);
    • правый щелчок по папке → «Экспорт папки в файл Outlook (.pst)…»;
    • командная палитра: «Экспорт и импорт файла Outlook».
  2. Выберите, что выгрузить: весь ящик или папку. Для папки можно включить или выключить «Вместе с вложенными папками».
  3. Нажмите «Выбрать файл и начать» и укажите, куда сохранить файл.

Пока идёт выгрузка, окно показывает папку, число писем и размер файла. Окно можно скрыть кнопкой «Скрыть»: выгрузка продолжится, а когда закончится, внизу появится итог. «Отменить экспорт» останавливает выгрузку; недописанный файл не остаётся.

В файл попадают письма с вложениями и вложенными письмами, отметки «прочитано», флажки, важность, категории, даты получения и отправки, подписанные и зашифрованные письма — в том виде, в каком они лежат в ящике.

Открыть файл в Outlook: «Файл → Открыть и экспортировать → Открыть файл данных Outlook».

Загрузить файл в ящик

  1. Правый щелчок по любой папке → «Импорт из файла Outlook (.pst)…» или меню «Файл → Экспорт и импорт (.pst)…» → «Импорт из файла».
  2. Нажмите «Выбрать файл…». OutTalk покажет папки файла и число писем.
  3. Выберите, куда загрузить:
    • «В новую папку» — папки файла появятся внутри папки «Импорт — имя файла»;
    • «В те же папки ящика» — письма лягут в папки с теми же именами, недостающие папки будут созданы, «Удалённые» файла — в «Удалённые» ящика.
  4. Нажмите «Импортировать».

Загруженные письма — обычные полученные письма, не черновики: с датами получения и отправки, отметкой «прочитано», флажком, важностью и категориями из файла.

Ограничения

  • Переносится только почта. Календарь, контакты, задачи и заметки из ящика не выгружаются, а из файла не загружаются; итог перечисляет такие папки и элементы.
  • Повторная загрузка того же файла создаёт копии писем.
  • Загрузить файл можно только в свой ящик; ящик, открытый по доступу, можно только выгрузить.
  • Если письмо не перенеслось (сервер его не отдал или не принял), выгрузка или загрузка продолжается, а письмо с причиной будет в итоге. Если пропала связь, закончилось место в ящике или вход перестал действовать, работа останавливается.
  • Закрытие окна OutTalk останавливает выгрузку или загрузку.
  • Outlook по умолчанию открывает файлы данных до 50 ГБ.

Открыть файл отдельным ящиком

Файл .pst можно не загружать в ящик, а открыть рядом с ящиками, как «Открыть файл данных Outlook» в Outlook:

  • «Файл → Открыть файл данных Outlook…» (на macOS — в меню OutTalk), командная палитра или «Настройки → Почтовые ящики → Открыть файл Outlook (.pst)».

Файл появится в списке ящиков под своим названием. Его папки и письма можно читать, искать по теме, отправителю и адресатам, открывать вложения и сохранять письма.

С письмами в файле работают как в обычном ящике: отмечают прочитанными и непрочитанными, ставят и снимают флажок, переносят между папками файла, удаляют. Удалённое попадает в «Удалённые» файла, а оттуда удаляется насовсем. Папки можно создавать, переименовывать, переносить и удалять; служебные папки файла («Удалённые» и папки, которые Outlook создаёт сам) не удаляются. В файл можно загрузить письма из другого файла через «Импорт из файла».

Перед первым изменением OutTalk сохраняет копию файла рядом с ним — «имя (копия до правок OutTalk).pst». Если места на диске для копии не хватает, OutTalk ничего не меняет и скажет, сколько нужно освободить. Копию можно удалить, когда она больше не нужна.

Отправить письмо, ответить или переслать из такого ящика нельзя: у файла нет сервера почты. Категории писем в файле видны, но не меняются.

Чтобы перенести письма из файла в ящик, используйте «Импорт из файла» в окне «Экспорт и импорт».

Если файл открыт в Outlook, OutTalk может не получить к нему доступ, а изменить его не сможет точно — закройте Outlook или уберите файл из его списка папок. Изменять файл старого формата (Outlook 97–2002) OutTalk не умеет — такой файл открывается только для чтения. Пока файл не используется, OutTalk его не держит. Убрать файл из списка: «Настройки → Почтовые ящики» → «⋯» у файла → «Убрать из OutTalk». Сам файл на диске при этом не удаляется, открыть его снова можно так же, как в первый раз.
